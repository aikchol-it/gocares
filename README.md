# gocares

GO CARES by AIKCHOL NEXT - บริการรับ-ส่งและดูแลผู้สูงอายุไปโรงพยาบาล

## Features
- บริการจองรถรับ-ส่งและผู้ดูแลโรงพยาบาล พร้อมเชื่อมต่อ LINE Official Account
- ระบบค้นหาข้อมูลอัจฉริยะ (AI Search & Assistant Chat Widget)
- ระบบจัดการเนื้อหาและแคมเปญ (Content Management & Tracking Dashboard)
- แดชบอร์ดสรุปสถิติและวิเคราะห์พฤติกรรมผู้ใช้งาน (Analytics & Marketing Tracking)

## Tech Stack
- Next.js 14 (App Router)
- React 18
- TypeScript
- Fuse.js (Fuzzy Search & Knowledge Base)
- Tailwind CSS / Lucide React

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm start
```
